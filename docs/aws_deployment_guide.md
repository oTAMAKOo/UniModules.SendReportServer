# AWS デプロイ手順書

この手順書は、ログサーバーをAWS上に構築するための手順です。
サーバーエンジニアでなくても実行できるレベルで記載しています。

---

## 構成を選んでください

| 構成 | インスタンス | RAM | 月額目安 | 対象 |
|------|------------|-----|---------|------|
| [安価版](aws_deploy_budget.md) | t4g.nano | 0.5GB | **~400〜600円** | 個人開発、小規模 |
| [通常版](aws_deploy_standard.md) | t4g.micro | 1GB | **~700〜1,100円** | チーム開発、中規模 |

> どちらもARM（Graviton）インスタンスを使用します。Docker イメージは自動でARM用にビルドされるため、特別な対応は不要です。

### 構成の違い

| 項目 | 安価版（t4g.nano） | 通常版（t4g.micro） |
|------|-------------------|-------------------|
| RAM | 0.5GB | 1GB |
| swap | 必要（1GB設定） | 不要 |
| PostgreSQL | メモリチューニングあり | デフォルト設定 |
| uvicorn ワーカー数 | 1 | 2 |
| 同時アクセス耐性 | 低い | 中程度 |
| リザーブドインスタンス適用時 | ~290円/月 | ~570円/月 |

### 迷ったら

- レポート件数が**1日数件〜数十件**程度 → **安価版**で十分
- レポート件数が**1日数百件以上**、または複数人で管理画面を同時利用 → **通常版**
- まず安価版で始めて、必要に応じて通常版にスケールアップも可能

---

## 全体の流れ（両構成共通）

```
1. 事前準備（AWS CLI インストール）
2. AWSアカウント・IAMユーザー作成
3. S3バケット作成（画像保存用）
4. EC2インスタンス作成
5. SSH接続 → サーバー初期設定
6. アプリケーション配置・起動
7. 動作確認
8. ドメイン・HTTPS設定（推奨）
9. 自動起動・バックアップ設定
```

構成別の手順書には、この各ステップの具体的なコマンドが記載されています。
