# AWS デプロイ手順書

この手順書は、ログサーバーをAWS上に構築するための手順です。
サーバーエンジニアでなくても実行できるレベルで記載しています。

> AWS 側の作業（バケット・IAM・インスタンス・DNS）を別の担当者に依頼する場合は、
> その人向けに範囲を絞った [aws_setup_handoff.md](aws_setup_handoff.md) を渡してください。
> 引き渡された情報を使ってサーバー内部を設定する手順が、以下の各構成の手順書です。

---

## 構成を選んでください

| 構成 | インスタンス | RAM | 月額目安 | 対象 |
|------|------------|-----|---------|------|
| [Lightsail版](aws_deploy_lightsail.md) | Lightsail 最小バンドル | 0.5GB | **$5 定額（~750円）** | **常時公開する場合の最安** |
| [安価版](aws_deploy_budget.md) | t4g.nano | 0.5GB | ~$8.4（~1,250円） | EC2 の運用に揃えたい場合 |
| [通常版](aws_deploy_standard.md) | t4g.micro | 1GB | ~$13（~1,960円） | 同時アクセスが多い場合 |

> **EC2 の月額にはパブリック IPv4 の課金（$0.005/時 = 約 $3.65/月）が含まれます。**
> 2024年2月から、インスタンスに割り当て済みの IPv4 アドレスも課金対象になりました。
> IPv4 と EBS だけで $4.4 になるため、リザーブドインスタンスで 1〜3 年コミットしても
> Lightsail の定額（IPv4・転送量込み）を下回りません。

> EC2 版は ARM（Graviton）、**Lightsail は x86_64** です。Docker イメージはどちらも
> 自動でビルドされますが、Docker Compose プラグインだけは手動でアーキテクチャを
> 選ぶため取り違えに注意してください（`linux-aarch64` / `linux-x86_64`）。

### 構成の違い

| 項目 | Lightsail版 | 安価版（t4g.nano） | 通常版（t4g.micro） |
|------|------------|-------------------|-------------------|
| RAM | 0.5GB | 0.5GB | 1GB |
| CPU | x86_64 | ARM | ARM |
| ディスク | 20GB（バンドル込み） | 8GB gp3 | 16GB gp3 |
| swap | 必要（1GB設定） | 必要（1GB設定） | 不要 |
| PostgreSQL | メモリチューニングあり | メモリチューニングあり | デフォルト設定 |
| uvicorn ワーカー数 | 1 | 1 | 2 |
| 同時アクセス耐性 | 低い | 低い | 中程度 |
| 課金の形 | 定額（時間割り） | 従量（インスタンス+IPv4+EBS） | 従量（同左） |
| 1年RI適用時 | 適用不可（元から定額） | ~$6.9（~1,030円） | ~$10（~1,530円） |
| 停止したとき | **課金は止まらない** | コンピューティング代のみ止まる | 同左 |

### 迷ったら

- **常時公開するなら Lightsail 版**。最小構成同士で比べて最も安く、定額なので請求が跳ねない
- レポート件数が**1日数百件以上**、または複数人で管理画面を同時利用 → **通常版**
- 他のリソースを EC2 で運用していて、運用手順を揃えたい → 安価版 / 通常版
- 使わない期間が長い場合、**Lightsail は停止では安くならない**（スナップショットを取って
  インスタンスを削除する）。逆に EC2 は停止すればコンピューティング代が止まるが、
  IPv4 と EBS の課金は残る

## 全体の流れ（全構成共通）

```
1. 事前準備（AWS CLI インストール）
2. AWSアカウント・IAMユーザー作成
3. S3バケット作成（画像保存用）
4. インスタンス作成
5. 固定IP・ファイアウォールの設定
6. SSH接続 → サーバー初期設定
7. アプリケーション配置・起動
8. 動作確認
9. ドメイン・HTTPS設定
10. 自動起動・バックアップ・証明書自動更新
```

構成別の手順書には、この各ステップの具体的なコマンドが記載されています。

ステップ 4〜5 だけが構成ごとに違います（EC2 はセキュリティグループと Elastic IP、
Lightsail はインスタンスファイアウォールと静的 IP）。6 以降はほぼ共通で、
違うのは Docker Compose プラグインのアーキテクチャだけです。
