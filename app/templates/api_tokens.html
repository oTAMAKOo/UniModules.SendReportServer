Claude Code での使い方

各メンバーは、トークンを発行して緑の枠のコマンドを実行するだけです（環境変数 BUGLOG_TOKEN に保存されます）。 MCP サーバーの登録はプロジェクトの .mcp.json で一度だけ行い、チームで共有します。 あとはレポートの URL（{{ PREFIX }}/p/<slug>/detail/…）を Claude に貼るだけで、Claude が get_report ツールでログ全文を読みます。 トークン 1 つで参加している全プロジェクト{% if project_slugs %}（{{ project_slugs | join(', ') }}）{% endif %}のレポートを読めます。 検索（search_reports / list_recent_reports）は参加プロジェクトが 2 つ以上あるとき project（slug）の指定が必要です（1 つなら省略可）。 手順の詳細はリポジトリの docs/claude_integration.md にあります。

{% if mcp_enabled %}
プロジェクトで共有する場合（リポジトリ直下の .mcp.json。トークンは含めない） 
{
  "mcpServers": {
    "buglog": {
      "type": "http",
      "url": "{{ mcp_url }}",
      "headers": {
        "Authorization": "Bearer ${BUGLOG_TOKEN}"
      }
    }
  }
}
プロジェクトに .mcp.json が無く、自分の環境だけに登録する場合（claude コマンドが使える環境のみ。デスクトップアプリだけでは使えません） 
claude mcp add --transport http --scope user buglog {{ mcp_url }} --header "Authorization: Bearer ${BUGLOG_TOKEN}"
{% else %}

この環境では MCP サーバーが無効になっています（.env の MCP_ENABLED）。読み取り API のみ使えます。

{% endif %}
